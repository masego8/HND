Database Design & Management

This unit focused on data modeling, normalization (1NF, 2NF, 3NF), ER diagrams, SQL querying, and database management principles.

Key Topics Covered

  • Normalization (up to 3NF)
  • Entity Relationship Diagrams (ERDs)
  • SQL Queries (SELECT, INSERT, UPDATE, DELETE)
  • Data Dictionaries & Constraints

Tools Used

  • MariaDB
  • MySQL Workbench / DBeaver
